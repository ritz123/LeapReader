- (constraint) Electron ^34, pdfjs-dist ^4.10, TypeScript ~5.6, Vite ^6, electron-builder ^25 — existing brownfield stack, all AI code must be additive and branch-isolated
- (version) ollama (Python) 0.6.2 (PyPI 2026-04-29); fastapi latest; uvicorn latest; pypdf>=4; duckduckgo-search latest; requests latest — stack from manuscript2presentation, version-pinned in pyproject.toml
- (decision) AD-1: Sidecar-process layered paradigm. Renderer (TS) <-> Main (Electron IPC) <-> Python FastAPI sidecar (HTTP/SSE localhost random port) <-> Ollama (localhost:11434). No direct renderer-to-backend or renderer-to-Ollama calls. Prevents: renderer coupling to backend port details; backend coupling to Electron API.
- (decision) AD-2: pane_id ('left'|'right') is the universal routing key for all backend API calls and conversation state. Backend keyed map (pane_id, session_id) -> conversation history. Prevents: cross-pane context bleed; shared state bugs in split-view.
- (decision) AD-3: SSE is the only streaming channel (backend -> main via HTTP, main -> renderer via IPC relay). No WebSocket. Four event types: token, tool_call, meta, error — each with pane_id and payload. Prevents: parallel streaming protocols; ambiguous event routing between panes.
- (decision) AD-4: SSE envelope schema fixed: {type: 'token'|'tool_call'|'meta'|'error', pane_id: 'left'|'right', payload: {...}}. meta carries flags: context_truncated, review_offline, model_no_tools. Prevents: untyped event parsing divergence between backend and renderer.
- (decision) AD-5: Process ownership chain. Electron main owns Python sidecar (spawn, port wait, kill on app-close). Python sidecar owns Ollama (detect PATH, download to userData, start, monitor). No other component may spawn or kill these. Prevents: dual spawns, zombie processes, competing lifecycle owners.
- (decision) AD-6: Context never crosses pane boundary. Backend conversation store keyed (pane_id, session_id). Clear resets session_id only for that pane. Prevents: cross-pane context leakage, shared session bugs.
- (decision) AD-7: Extraction strategy is mode-specific and immutable. Chat/Summarize: frontend sends pdfjs text in request body (8000-token cap). Review: frontend sends PDF file path; backend extracts via pypdf (50000-char cap, PAGE BREAK markers). These two paths must never be swapped by either builder. Prevents: inconsistent extraction paths.
- (decision) AD-8: Tool-call capability detection happens at review invocation time. Backend checks active model's capabilities via ollama.show() or catches ToolNotSupportedError on first call; falls back to non-tool review and emits meta event {model_no_tools: true}. Prevents: silent tool-call failures; inconsistent review output across models.
- (decision) AD-9: Port negotiation. Backend writes its bound port to app.getPath('temp')/leapreader-backend.port after binding. Main polls this file with 100ms interval up to 10s. Renderer receives port via IPC channel 'backend:ready:{port}'. Prevents: hardcoded port conflicts; race conditions on startup.
- (decision) AD-10: Managed Ollama binary stored in app.getPath('userData')/ollama/bin/. System PATH checked first; if found, system binary used. Prevents: redundant downloads; permission issues writing to system dirs.
- (decision) AD-11: pane-origin tagging for #selection-float. Selection event listeners in each pane set data-pane-id='left'|'right' on the shared #selection-float overlay before showing it. FR-18 reads this attribute when routing Ask AI. Prevents: selection routed to wrong pane.
- (decision) AD-12: Branch isolation. All AI code (src/ai/, backend/, electron/ai-bridge.mjs, extraResources config) lives on feature/ai-assistant branch. main branch build config does not reference AI extraResources. Prevents: AI code in Android/web builds; untested AI code reaching main.

- (decision) AD-13: Abort chain is a four-layer handshake: renderer IPC ai:abort → Main HTTP DELETE → sidecar asyncio cancel → terminal SSE error{code:ABORTED}. Renderer treats ABORTED as clean stop. Prevents: partial aborts that leave Ollama generating or renderer stuck.
